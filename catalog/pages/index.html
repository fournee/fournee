Fournée

A theming toolkit, in one place: Frosting for colour, Fontdant for type, and the kitchen that checks them together. Every project takes its colours from Frosting's roles and its type from Fontdant's steps and faces, never from hard-coded values.

The catalog

Frosting

Colour roles, ready-made looks, 🎲, gradients and the readability checks.

Fontdant

Type presets with samples, the size ladder for each mode, and the self-hosted font library.

Spec

The House spec and 21 standards (WCAG, government, NASA, CERN…), rule by rule.

The four steps

The panel every project gets, live: Frosting, Fontdant, Spec, Expo.

How you use it

1Frosting

Build around a client's colours, start from a look or a lucky roll, then fine-tune each role.

2Fontdant

Pick a type preset or roll one, then faces, size, mode, or add the client's own font.

3Spec

The standard the page is held to. Compare another side by side, fit to it, adopt it or keep yours.

4Expo

The final check of colour and type together; every problem links to its fix. One Publish.

Where things live

  • Source: fournee/fournee on GitHub (MIT). Frosting and Fontdant live there.
  • Research: docs/research/. Design decisions: docs/decisions/.
  • For Claude: the fournee skill and the "Design system: Fournée" rule, installed by Install-Fournee-Everywhere.bat.
  • In a project: type/recipe.json plus type/build-type.mjs copy Fournée's built files in. Never edit the copies; change Fournée and rebuild.
