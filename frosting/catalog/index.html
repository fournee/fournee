The rule Part A

Never hard-code a colour. Name its role. A look is just a set of values for the roles, so swapping it is one setProperty per role.

.card    { background: var(--fr-surface); color: var(--fr-text); }
.dot.up  { color: var(--fr-ok); }
.chart   { stroke: var(--fr-series-1); }

This page is frosted with the same variables. Everything you see below, including the panel, follows whatever look you pick.
